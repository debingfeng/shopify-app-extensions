# Standhigher Lab demo search

Use `search_lab_demos` when a merchant asks what Standhigher Lab demonstrates or wants to find a specific npm component or Shopify extension example. Pass a short topic as `query`; omit it to list the available examples. Summarize only the returned demo descriptions and offer their app links. These examples use mock data or learning scenarios; do not describe them as live store data or as actions that change the store.
